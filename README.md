# Computing Safe Partial Rollbacks from Compressed Checkpoint Logs

Reproduction code and numerical results for the manuscript by **Siyuan Qiu and Jianfeng Xu**.

If two checkpoints produce the same log message, the controller can undo an event only when that command is safe in both. The scripts test which undo sequences remain safe and how many bits a log needs to guarantee a given rollback depth. All experimental inputs are finite event orders, checkpoint families and source probabilities generated by the scripts. No external dataset is required.

## Quick start

Use Python 3.11 or later and run the commands from the repository root. Leave Python assertions enabled (the default). Verifying the saved results uses only the standard library.

```sh
git clone https://github.com/caimiaomiao6/safe-partial-rollbacks.git
cd safe-partial-rollbacks
python check_foundations.py
python nonuniform_rollback.py --check nonuniform-results.json
```

The first command after `cd` compares the decoder with direct enumeration. The second verifies all 80 saved rate intervals, covering five source laws at 16 mean depths each. Expected output:

```text
526 block cells passed, including 468 nonrectangular cells.
Strict gap for the uniform nontransitive source verified exactly.
Verified all fixed-depth upper and lower bounds.
```

## Reproduce a particular result

| Manuscript result | Command | What to look for |
| --- | --- | --- |
| Longest safe undo sequence (Section 3) | `python check_decoder.py` | Checks the returned events and executes the proposed sequence on every candidate checkpoint in each of 104,794 message cells. |
| Block decoding and symmetry (Sections 4–6) | `python check_foundations.py` | Tests 526 two-coordinate cells and verifies the strict counting gap for the three-checkpoint example. |
| Exact rate curve on a uniform fork (Section 6, Table 1) and guaranteed depth (Section 7) | `python verify_rollback.py` | Prints the curve vertices. For 8 workers with 4 active, the critical chain length is 3. The two-checkpoint example on the complete graph with four vertices needs 7 messages. |
| Binary search for the curve vertices (Section 6) | `python check_tangent.py` | Compares the search with a full lower-hull scan on 6,325 parameter triples and checks a chain of length `10^100`. |
| Initial rate under nonuniform probabilities (Section 6) | `python check_fork_slope.py` | Checks 84 initial slopes against direct enumeration. |
| Nonuniform rates (Section 6, Table 2 and Fig. 2) | `python nonuniform_rollback.py --check nonuniform-results.json` | Recomputes each saved lower and upper bound from its numerical witness using rational arithmetic and outward bounds for logarithms. |
| Checkpoint model and rate calculations (Sections 2, 3 and 6) | `python audit_rollback.py` | Prints a JSON summary of structural checks on 407 orders and 21 numerical comparisons. |

## Read or regenerate the results

- [verification-results.txt](verification-results.txt) contains the expected output of `verify_rollback.py` below the article metadata.
- [audit-results.json](audit-results.json) contains the summary from `audit_rollback.py`. The deposited file also includes article metadata.
- [nonuniform-results.json](nonuniform-results.json) contains the 80 certified intervals. Each row identifies a source law (`alpha`) and a target mean depth (`depth`). Divide `lower_trillionths` and `upper_trillionths` by `10^12` to obtain bits per checkpoint. The `witness` field lets the checker verify the interval independently of the search that produced it.

To generate fresh witnesses, install NumPy in your Python environment and write the results to a new file:

```sh
python -m pip install numpy==2.3.5
python nonuniform_rollback.py --output reproduced.json
python nonuniform_rollback.py --check reproduced.json
```

Floating-point searches can produce different witnesses across platforms. The final command checks the bounds for the witnesses your run produced.

The [version cited in the manuscript (`eac1f78`)](https://github.com/caimiaomiao6/safe-partial-rollbacks/tree/eac1f7876ff2452def27620ca16d85cd105bc9be) preserves the experimental files used for the paper. The section and figure numbers above follow the current manuscript.
